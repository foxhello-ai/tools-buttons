# README 界面截图

- `desktop-buttons.png`：当前 Swift / AppKit 程序通过自带 `--snapshot --verify-hover` 路径渲染的原生按钮及独立悬浮提示，保留透明背景。
- `task-flow.jpg`：在隔离示例项目中，点击默认“运行项目检查示例”按钮并完成真实 Shell 任务后的 Web 页面截图。
- `node-logs.jpg`：在同一任务中点击“统计文件”节点，筛选对应结构化日志后的页面截图。

任务截图使用初始化模板生成的两个按钮和三步检查脚本，项目展示名设为“Tools Buttons 示例项目”。
页面由本仓库的执行服务提供，截图通过 Codex 浏览器工具获取。示例目录和日志均为临时测试数据。
Web 任务详情与桌面 WKWebView 共用实现；这两张 Web 截图不代表完整的原生任务窗口外框。
